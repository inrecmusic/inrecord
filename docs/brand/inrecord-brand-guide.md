# InRecord 視覺風格指南（行銷素材用）

版本 2026-09-11｜依據 inrecordmusic.com 原始碼與桌機 1440／手機 390 畫面實測
適用：廣告圖、社群貼文、活動視覺、落地頁
不適用：站上的「教室」與「後台」另有兩套完全不同的風格，不要套用到行銷素材

---

## 0. 濃縮版（若只讀一段，讀這段）

為 InRecord（台灣線上流行鋼琴課程）製作行銷素材。品牌調性是**音樂會節目單**，不是一般線上課程銷售頁。

- **色彩極度克制**：底色只用近黑 `#05070b` 或近白 `#f8fafc`，兩者不混。主色藍 `#2563eb` 只用在按鈕、小標與線稿圖解，整張圖藍色面積不超過 5%。金色 `#ecbf5c` 只用在「限時／資格／系列名」一處，面積不超過 4%，且只疊在深底。品牌紅 `#e01919` 只以一顆小圓點出現，代表錄音鍵。禁止第二強調色、禁止多彩漸層。
- **字體**：中文標題用思源宋體 600，中文內文用思源黑體 400，英數用 Inter。標題襯線、內文黑體，不可反過來。數字一律用 Inter，不用襯線體。
- **構圖**：文字區佔畫布 45–60%，絕不滿版。深色素材上照片用降透明度壓在純黑底，不要蓋半透明黑遮罩。留白四邊各 8–11%。
- **影像**：舞台實拍，紅色側燈、近全黑背景、演奏者低頭側面不看鏡頭。不要笑臉、不要圖庫感、不要扁平插畫。要表現教學內容就用藍色線稿鍵盤圖解。
- **禁止出現**：三欄 icon 特色卡、學員頭像見證、橘黃色促購按鈕、跳動數字、緞帶徽章滿版、多張方案卡並列。

## 1. 品牌調性

四個能區辨的詞，每個都對應畫面上量得出來的事實。

1. **節目單感，不是銷售頁**。襯線標題、01–05 編號索引、17–24 字短行長、內文永遠比版心窄 40%、字距 0.3em 的英文小標。
2. **兩幕式：暗場開演，亮燈翻譜**。首屏是 62% 純黑加舞台紅的劇場暗場，只佔全頁 8%；其餘 92% 是 77% 白的教科書。素材要嘛全深、要嘛全淺，不要折衷成中間調。
3. **藍墨線稿的音樂圖解**。課程重點區佔全頁 37.7%，主角是 13 個自製圖解元件。這是唯一無法被競品複製、也無法用圖庫取代的資產。
4. **極端克制**：一個藍、一片金箔、一顆錄音紅。全頁只有 2.4% 藍、0.3% 金。紀律本身就是這個品牌的視覺個性，多加一個顏色就不像了。

### 與一般線上課程平台的差別

| 一般課程站 | InRecord 實際 |
| --- | --- |
| 亮色多彩配色組 | 單一藍 2.4% ＋ 金 0.3% |
| 圓潤無襯線標題 | 襯線宋體標題，小標以下才黑體 |
| 笑臉學員與講師照 | 零學員照，講師低頭側面不看鏡頭 |
| 三欄 icon 特色卡 | 沒有（樣式還在程式裡，畫面上已刪光） |
| 頭像見證輪播 | 沒有，只有一行文字社會證明 |
| 扁平向量插畫 | 自製音樂圖解（鍵盤、和弦、節奏） |
| 橘黃色促購按鈕 | 藍色按鈕，金色只給資格與限時 |
| 整頁明亮 | 8% 黑場劇院 ＋ 92% 白紙 |
| 多張方案卡並列 | 單張方案卡置中 |

一句話：它看起來不像在賣課，像在賣一場演出的入場券，而課本夾在票裡。

### 2.1 實測佔比（先看這個，再看色碼）

桌機首屏像素分佈：

| 元素 | 佔比 |
| --- | --- |
| 近黑底 | 62.0% |
| 舞台紅（照片） | 24.9% |
| 品牌藍 | 2.1% |

全頁則是 77% 白、2.4% 藍、0.3% 金。**藍色最大的一塊就是那顆 310×56px 的購買按鈕。不要讓藍色大面積出現。**

**兩個紅不要混**：字標紅點是 `#e01919`，CTA 脈動點是 `#ff2028`（更亮偏橘）。

### 2.3 金色只有兩種正確用法

DO：
- **深底上的金＝身分標記**。限時、粉絲資格、系列名、星等。用 `#ecbf5c` 或金箔漸層。
- **淺底上的金＝圖解高亮**。只出現在鍵盤或和弦圖解裡，標示「注意這一顆」。用 `#f7d68a` 實心填色。

DON'T：
- 金色當主色或大面積背景。
- 金色配在一般淺底文字上（淺底的金只屬於圖解）。
- 同一張圖出現三種不同的金。對外只用一組：`#f5d488` / `#ecbf5c` / `#d9a13a`。

### 2.4 深底文字對比（實測 WCAG）

| 組合 | 對比 | 判定 |
| --- | --- | --- |
| 白 100% 疊 `#05070b` | 20.2:1 | 可 |
| 白 82% 疊 `#05070b` | 13.3:1 | 副標可 |
| 白 66% 疊 `#05070b` | 8.8:1 | 內文可 |
| 白 45% 疊 `#05070b` | 4.5:1 | 只有大字可（刪除線原價） |
| 金 `#ecbf5c` 疊 `#05070b` | 11.7:1 | 可 |
| 藍漸層暗端 `#2c68e7` 疊 `#05070b` | 4.07:1 | 內文不合格 |

藍色漸層剪字是全站最弱的一環。漸層暗端不要低於 `#4f86ea`，或縮短漸層行程讓最暗處只吃到最後一兩個字。

### 2.5 淺色分層

`#f8fafc` 與 `#ffffff` 的對比只有 1.04:1，人眼分不出來。**素材上當成單一淺底處理，靠卡片的 1px `#e2e8f0` 邊線分層，不要靠底色交替。**

## 3. 文字

### 3.1 字族與角色

| 角色 | 英數 | 中文 | 用在哪 |
| --- | --- | --- | --- |
| 標題 | Cormorant Garamond 600 | Noto Serif TC 600 | 主標、所有區塊大標 |
| 內文與介面 | Inter 400／600／700 | Noto Sans TC 400／500／600／700 | 說明文、按鈕、卡片、標籤 |
| 等寬裝飾 | JetBrains Mono 700 | （無中文，自動落黑體） | 系列名、金膠囊、倒數、英文小標 |

替代字型：思源宋體或 Noto Serif CJK 取代 Noto Serif TC；思源黑體或蘋方取代 Noto Sans TC；Inter 沒有就用 Helvetica Neue 或 SF Pro。**不要用圓體、不要用粗黑標題**，那會立刻失去節目單感。

### 3.2 字級階層（桌機實際值）

| 元素 | 字族 | 字級 | 字重 | 行高 | 字距 | 顏色 |
| --- | --- | --- | --- | --- | --- | --- |
| 英文小標 kicker | 黑體／等寬 | 13px | 700 | — | .3em 全大寫 | `#2563eb` |
| 系列名 | 等寬 | 15–22px | 700 | 1.1 | .02em 全大寫 | `#ecbf5c` |
| 主標 | 襯線 | 36–62px | 600 | 1.12 | .01em | 白 |
| 副標 | 襯線 | 21–31px | 500 | 1.36 | — | 白 82% |
| 區塊大標 | 襯線 | 30–52px | 600 | 1.1–1.22 | .01em | `#0f172a` |
| 導言 | 黑體 | 18–22.5px | 400 | 1.6 | — | 白 66% ／ `#64748b` |
| 內文 | 黑體 | 17–20px | 400 | 1.65–1.75 | — | `#64748b` |
| 價格 | Inter | 46px | 800 | 1 | −.01em | 白 |
| 刪除線原價 | Inter | 22px | 500 | — | — | 白 45% |

手機（≤640px）：主標降到 30–44px、導言 18px、價格 36px、原價 20px。

### 3.3 字距三規則

- 全大寫英文小標一律拉開：0.08em–0.3em，字級越小拉越開。
- 中文襯線大標微張 +0.01em。
- 數字與黑體標題收緊：價格 −0.05em 到 −0.01em。

### 3.4 兩個實測踩到的坑

1. **Cormorant 的預設數字是舊式數字**。「10」會渲染成像「1O」、「2」變下標小字。在網頁上有味道，在廣告圖上會被當成 bug。**含數字的大標不要用襯線英文字**，改用黑體或思源宋體自帶的數字；價格永遠用 Inter 800。
2. **Cormorant 600 的視覺重量明顯輕於思源宋體 600**。中英同行的標題要手動補償：英文加一階字重，或中文降到 500。

### 3.5 中文斷行

全站規則是 `word-break: keep-all` 加 `line-break: strict`：詞不從中間斷開，行首不出現句讀。做圖同理，**不要讓「坐姿」斷成「坐／姿」、「鍵盤」斷成「鍵／盤」**。標題要換行就自己指定斷點，不要用空白硬排。

## 4. 版面與構圖

| 項目 | 桌機 1440 | 手機 390 |
| --- | --- | --- |
| 內容版心 | 1120px | 358px |
| 左右留白（佔畫布） | 160px · 11.1% | 16px · 4.1% |
| 區塊上下留白 | 96px | 48px |
| 標題與下方內容間距 | 40px | 28px |
| 內文最大寬度 | 620–720px | 100% |
| 每行字數 | 17–23 字 | 12–19 字 |

**全站最一致的規則：文字永遠比容器窄。** 版心 1120px，但沒有任何一段內文超過 720px，只佔 64%。做廣告圖時文案區抓畫布的 45–60%。

### 主視覺構圖公式

- 左 42%：純黑空板，零雜訊，完全沒有內容。
- 中 12%：過渡帶。照片往文字側淡出的漸層寬達 170px。不是硬邊，不是半透明黑遮罩，是一條很長的漸層。
- 右 35–45%：照片。
- 文字群組垂直置中略偏上，上下各留約 15%。
- **手機是另一種邏輯**：照片變全幅襯底、透明度降到 42%，文字直接壓在上面，整個首屏是暖調電影海報。手機素材不要照抄桌機的純黑左欄。

## 6. 音樂圖解系統（最不可替代的資產）

做教學型素材時優先用它，辨識度遠勝再拍一張黑底鋼琴照。

| 角色 | 色值 |
| --- | --- |
| 主要標記（大三和弦、目前音） | `#2563eb` |
| 次要標記（小三和弦） | `#172554` |
| 弱化標記（非重點音） | `#64748b` |
| 白鍵 | `#ffffff`，框 `#cbd5e1` |
| 黑鍵 | `#0f172a` |
| 提示高亮 | `#f7d68a`（淺底上唯一合法的金，實心填色） |
| 答對 | `#16a34a` |

畫在微暖白紙 `#fbf9f3` 上，配一條 56×3px 的酒紅短線 `#9c3540` 當標記。**主體是藍色圖解，整體仍看起來是白的，不要做成奶油黃。**

大三和弦與小三和弦的配色成對使用，**用錯就是講錯樂理**。

## 8. 社群版位與裁切

**不要裁主視覺，要重排主視覺。** 它是 3:2 橫幅、主體在右 45%，裁成方形會把左邊那塊純黑文字空板全部丟掉，裁成 1.91:1 會切到人物頭部。唯一的直幅品牌影像是講師形象照 800×1200，那才是 4:5 與 9:16 的素材來源。

正確做法是把三個構成元件重新在目標比例上堆疊：金色短線加系列名 → 白色襯線主標加藍色漸層關鍵詞 → 金膠囊或價格。照片依比例換成講師照或演奏情境照。

| 版位 | 尺寸 | 安全區 |
| --- | --- | --- |
| 分享縮圖 FB／LINE | 1200×630 | 文字高度不超過 60% |
| 方形貼文 | 1080×1080 | 四邊各留 8–10% |
| IG 主要版位 | 1080×1350 | 四邊各留 8–10%，用直幅講師照 |
| 限動與短影音 | 1080×1920 | 上留 14%、下留 20% |

## 9. 動態

- **唯一的品牌曲線**：`cubic-bezier(0.22, 1, 0.36, 1)`，位移 28px 加淡入，0.6 秒，接力間隔 0.12 秒。起步快、尾巴很軟。
- **呼吸光暈是專屬語彙**，全站只掛在主要行動按鈕，2.2 秒一次。一支影片只能用一次。
- **錄音紅點脈動** 1.8 秒一次，代表錄音中。
- 輪播四秒一張。

## 10. 文案語氣

DO：
- 對外一律用「你」。「您」只用在寄給已購學員的正式通知信。
- 短句、逗號斷句、**零驚嘆號**。副標用「情境短句——白話補充句」的破折號公式（全形 ——）。
- 每個賣點掛一個可驗證的數字：10 章節加 2 附錄、58 個單元、約 8 小時、24 個三和弦（12 大＋12 小）、10 首簡易歌曲實戰。
- 術語可以講（三和弦、分解和弦、卡農和弦進行），後面一定接一句白話翻譯。
- 固定說法：學員、章節、單元、上架、方案、一次買斷、互動遊戲。
- 品牌寫法：InRecord｜音樂刻；課程書名《從零開始學鋼琴》；系列 Crossoverick Vol.1。

DON'T：
- 不要 AI 腔空話：賦能、打造、解鎖潛能、開啟音樂之旅、讓我們一起。
- 不要支語：視頻→影片、質量→品質、信息→資訊、在線→線上、默認→預設、用戶→學員、激活→開通、軟件→軟體。
- 不要寫「AI 鋼琴課」，對外一律「互動遊戲」。
- 不要用三個排比形容詞堆疊，不要用驚嘆號催促。

可沿用語感的真實例句：
- 「從鍵盤、中央 C、音名開始，不需要會看五線譜才能學。」
- 「一首接一首解鎖，學完就能彈出喜歡的歌 ── 真歌實戰，不只是練習曲。」
- 「留下 Email，試看影片連結馬上寄到你的信箱。」
- 「10 章節系統化學習，搭配互動遊戲練習，讓學鋼琴變得有趣、能追蹤成效，看見進步。」
