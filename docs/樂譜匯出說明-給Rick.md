# 樂譜匯出說明（給 Rick）

這份說明是告訴你：InRecord 教室的「互動樂譜」要怎麼從打譜軟體把譜匯出來。照著做，上傳到後台就能直接變成學員看到的五線譜、簡譜和播放。

## 一句話

**用 MuseScore 打好右手旋律＋和弦記號（或鋼琴雙手譜）→ 檔案 → 匯出 → 選 MusicXML → 存成 `.mxl`（或 `.musicxml`）→ 交給 Alan 上傳。**

## 1. 譜要長什麼樣子

兩種都可以：

- **只打右手旋律＋和弦記號**（最省事）：一行高音譜號的旋律，每個換和弦的地方輸入和弦記號（見第 2 點）。
  左手由系統依和弦自動配，學員可以在柱式與第 8 章 8-2～8-8 的伴奏型態之間切換；和弦之後也能在後台直接改。
- **鋼琴大譜表兩行**：上面一行是右手（高音譜號），下面一行是左手（低音譜號）。
  要學員照**老師編好的左手**彈就用這種；系統會預設顯示原譜左手，學員也能改用自動伴奏。

另外：

- 三行以上的譜（例如多個樂器的總譜）系統會擋下來。
- 只有右手、又沒有和弦記號的譜也收，但沒辦法自動配左手，學員只會看到右手旋律。
- 一首曲子一個檔。

## 2. 和弦名怎麼輸入

- 和弦名（C、G7、Am、C/E…）要用打譜軟體的**「和弦記號」**功能輸入。
  MuseScore：選一個音符後按 **Ctrl+K**（Mac 是 **⌘+K**），再打和弦名。
- **不要**用一般文字（Ctrl+T 的「譜表文字」）打和弦名——那樣系統讀不到，學員就看不到和弦、級數，也不能點和弦看組成音。
- 轉位和弦用斜線寫，例如 `C/E`、`G/B`。
- 整首都沒有和弦名也可以，學員那邊就不會出現和弦相關的按鈕；但只有右手時就沒辦法自動配左手。

## 3. 怎麼匯出（MuseScore 4）

1. 打開樂譜，選單 **檔案 → 匯出…**
2. 「匯出為」選 **MusicXML**。
3. 檔案格式選一種：
   - **壓縮的 `.mxl`**（建議，檔案小）
   - 或未壓縮的 **`.musicxml`**
4. 按「匯出」存檔。

其他打譜軟體（Sibelius、Finale、Dorico）也都有「匯出 MusicXML」，一樣選 `.mxl` 或 `.musicxml` 就好。

## 4. 系統看得懂的記號

這些會正確顯示在五線譜、簡譜，播放也照著走：

- 音符與休止符
- 鋼琴大譜表兩行（上右手、下左手），或只有右手一行（左手自動配）
- 同時按的音（和弦音）
- 調號與曲中轉調
- 拍號與曲中變拍（例如 4/4、3/4、6/8）
- 附點
- 連結線
- 三連音
- 臨時升降與還原記號
- 和弦記號（和弦名）
- 速度標示
- 反覆記號與第一／第二結尾（播放會展開）
- 弱起小節

## 5. 會被略過的記號

下面這些**五線譜上照樣看得到**，但簡譜不畫、播放也不會照著做。上傳時後台會列出警告，提醒 Alan 這首用到了哪些：

- 踏板記號
- 表情記號（強弱，例如 p、f）
- 漸強／漸弱記號
- 裝飾記號（顫音、迴音等）
- 裝飾音（倚音）
- 延長記號
- 歌詞
- D.S.／Coda 跳躍記號（不展開）

> 反覆記號 `|: :|` 和第一、第二結尾，播放時會照順序展開；但 **D.S.、D.C.、Coda 這類跳躍不會展開**，播放會從頭順順地走到尾。需要跳躍的曲子，請直接把要重複的段落寫出來。

另外兩點：

- 同一隻手同時有兩個聲部、節奏又不一樣（例如右手旋律加內聲部），五線譜照畫，但**簡譜只會顯示第一個聲部**，後台也會警告。
- 速度請用軟體的「速度標記」（例如 ♩ = 96），系統會拿來當預設播放速度。

## 6. 檔名

`單元編號_曲名_v版本.mxl`

例如：`1-2_小蜜蜂_v1.mxl`、`3-4_小星星_v2.mxl`

改了譜再交一次時，版本號加 1，Alan 在後台「替換新版」就好。

## 7. 交檔之後

Alan 會在後台「課程管理 → 曲目」上傳。上傳當下會：

- 檢查是不是鋼琴譜（右手一行或雙手兩行；三行以上就擋下，並說明原因）；
- 列出被略過的記號（上面第 5 點）；
- 可以先預覽學員看到的畫面，確認沒問題再發布、掛到單元。

第一批交檔後，我們會拿你的檔跟 MuseScore 的畫面逐小節比對，有對不上的地方再修系統。
