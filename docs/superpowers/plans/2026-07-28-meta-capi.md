# Meta CAPI（伺服器端 Purchase）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 付款成功時由 `notify` webhook 伺服器端送 Meta Purchase（補回瀏覽器 Pixel 漏掉的 10–30% 轉換），與瀏覽器 Purchase 靠共用 `event_id=mer_trade_no` 去重。全程 guarded、best-effort，絕不影響金流。

**Architecture:** 結帳擷取 `_fbp/_fbc`(client) + IP/UA(server) 存 `orders.capi_data`；`notify` 履約原子區塊內呼叫 `lib/meta-capi.sendPurchase`（guarded on token+meta 啟用）；Phase 1 `trackEvent` 讓瀏覽器 fbq 帶 `eventID` 對上去重。

**Tech Stack:** Next.js 14.2.35、Supabase、Meta Graph API v25.0 `/{pixel}/events`、Node crypto (SHA256)、Vitest。

設計依據：`docs/superpowers/specs/2026-07-27-ad-tracking-capi-meta-conversions-design.md`。

## Global Constraints
- **Guarded**：`META_CAPI_ACCESS_TOKEN` 未設 或 Meta 未在追蹤碼分頁啟用（`getTrackingSettings().meta` 為空）→ `sendPurchase` 直接 return `{skipped}`，不送。
- **Best-effort**：`sendPurchase` 整段 try/catch 永不拋；notify 呼叫端再包 try/catch。**絕不影響 notify 的付款確認/開通/寄信/開票**（金流最優先）。
- **去重**：CAPI `event_id` = `mer_trade_no`；瀏覽器 Purchase 經 `trackEvent` 帶 `eventID` = `transactionId`（= mer_trade_no）。兩者一致 → Meta 只算一次。
- **PII**：email 送出前 `SHA256(trim+lowercase)`；`fbp/fbc/ip/ua` 原樣（Meta 規範這四個不 hash）；token 放 POST body 不入 URL、不落 log。
- **Pixel id 來源**：讀 `getTrackingSettings().meta.id`（複用 Phase 1，單一事實來源）。
- **一次性**：CAPI 送出掛在 notify 既有 `fulfilled_at` 原子 claim 的 `if (claimed)` 區塊內（每單一次）；即便偶發重送，Meta 也以 event_id 去重。
- **測試**：Vitest node；`npx vitest run <path>`；esbuild/oxc 警告忽略。
- **Git**：分支 `feat/point2-carousel`；只 add 明確路徑；commit 尾加 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`。
- **部署**：`supabase-capi.sql` 先套正式 DB → push → vercel --prod。無 cron。

Create `lib/meta-capi.js`:
```js
// lib/meta-capi.js — Meta Conversions API 伺服器端 Purchase。純 builder + guarded send（永不拋）。
import crypto from "crypto";
import { getTrackingSettings } from "./tracking.js";

const sha256 = (s) => crypto.createHash("sha256").update(String(s).trim().toLowerCase()).digest("hex");

// 純：組 CAPI event 物件
export function buildPurchaseEvent({ merTradeNo, amount, plan, email, capiData, attribution, eventTime }) {
  const cd = capiData || {};
  const user_data = {};
  if (email) user_data.em = [sha256(email)];
  if (cd.fbp) user_data.fbp = cd.fbp;
  const fbc = cd.fbc || (attribution?.fbclid ? `fb.1.${eventTime}.${attribution.fbclid}` : null);
  if (fbc) user_data.fbc = fbc;
  if (cd.ip) user_data.client_ip_address = cd.ip;
  if (cd.ua) user_data.client_user_agent = cd.ua;
  const siteUrl = process.env.NEXT_PUBLIC_SITE_URL || "https://inrecordmusic.com";
  return {
    event_name: "Purchase",
    event_time: eventTime,
    event_id: merTradeNo,
    action_source: "website",
    event_source_url: `${siteUrl}/success`,
    user_data,
    custom_data: { currency: "TWD", value: Number(amount) || 0, content_ids: [plan], content_type: "product" },
  };
}

// guarded：僅在 token 有設 且 Meta 已於追蹤碼分頁啟用時送。永不拋。
export async function sendPurchase({ merTradeNo, amount, plan, email, capiData, attribution }) {
  try {
    const token = process.env.META_CAPI_ACCESS_TOKEN;
    if (!token) return { skipped: "no_token" };
    const platforms = await getTrackingSettings();
    const pixelId = platforms?.meta?.id;
    if (!pixelId) return { skipped: "meta_disabled" };
    const ver = process.env.META_API_VERSION || "v25.0";
    const eventTime = Math.floor(Date.now() / 1000);
    const event = buildPurchaseEvent({ merTradeNo, amount, plan, email, capiData, attribution, eventTime });
    const body = { data: [event], access_token: token };
    if (process.env.META_CAPI_TEST_CODE) body.test_event_code = process.env.META_CAPI_TEST_CODE;
    const res = await fetch(`https://graph.facebook.com/${ver}/${pixelId}/events`, {
      method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body),
    });
    const json = await res.json().catch(() => ({}));
    if (json.error) return { ok: false, error: `capi_${json.error.code || "err"}` };
    return { ok: true, fbtrace_id: json.fbtrace_id };
  } catch (e) {
    return { ok: false, error: e?.message || "capi_failed" };
  }
}
```
> ⚠️ 實作/部署時以 Context7（`/websites/developers_facebook_marketing-api`）確認當前 Graph API 版本與 CAPI `user_data`/purchase 規範。

```js
// Meta CAPI 匹配用：讀 Pixel 設的 _fbp / _fbc cookie（browser）
export function readFbCookies() {
  if (typeof document === "undefined") return {};
  const get = (n) => {
    const m = document.cookie.match(new RegExp("(?:^|; )" + n + "=([^;]*)"));
    return m ? decodeURIComponent(m[1]) : "";
  };
  const fbp = get("_fbp"), fbc = get("_fbc");
  return { ...(fbp ? { fbp } : {}), ...(fbc ? { fbc } : {}) };
}
```

```js
export function trackEvent(name, params = {}) {
  if (typeof window === "undefined") return;
  const eventId = params.eventId || params.transactionId;
  if (typeof window.fbq === "function") {
    if (eventId) window.fbq("track", name, metaParams(name, params), { eventID: eventId });
    else window.fbq("track", name, metaParams(name, params));
  }
  if (typeof window.gtag === "function") window.gtag("event", GA4_MAP[name] || name, ga4Params(name, params));
}
```
