鍵盤配色比較三種配色畫的是同一個瞬間：左手彈 C 和弦，Do、Mi 按對，Sol 誤按成 Fa，Sol 還在等你按。

A　左右手分色 建議

按下的鍵用「手的顏色」，跟樂譜的右手藍、左手橘一致。雙手合彈時一眼分得出哪隻手彈了什麼。

B　單色藍

不分左右手，按下一律是品牌藍。畫面最乾淨，但雙手合彈時看不出是哪隻手。

C　金色

按下用 InRecord 金色，最有品牌感。但跟「要按的鍵」同一個色系，對錯的對比比較弱。

學員的一輪練習

  1. 看影片：老師講解，右側樂譜跟著亮到正在講的小節。
  2. 停下來出題：播到互動點自動暫停，題目出現在鍵盤正上方，要按的鍵亮金色。
  3. 自己彈：「你按的」即時顯示按到哪些音；按錯的音變紅，告訴你差在哪。
  4. 彈對就繼續：整條變綠，按「繼續上課」或空白鍵，影片接著播。沒接琴的人按「我彈好了」。
金色只代表「現在要做的事」：要按的鍵（金色圓圈）、目前這題、老師正在講的小節。
琴鍵按下去才上色，顏色跟樂譜一致：左手橘、右手藍；按錯是紅色。
綠色只代表「完成／正確」。紅色只代表「要修正」。
主按鈕永遠在題目條右側同一個位置，文字說清楚會發生什麼事。
