# 互動樂譜 v2：右手旋律＋自動左手伴奏、後台自行新增／刪除 — 設計

日期：2026-10-30
前一版：`2026-10-29-interactive-score-v2-design.md`（第一批，已完成並部署 preview，分支 `feat/interactive-score-v2-batch1`）。本文件**改寫第一批 §1 的一項決定**：學員看到的左手不再只能是老師編好的；只有右手旋律的曲子，左手由系統依和弦產生，學員可切換伴奏型態。衝突時以本文件為準。

> **【Alan 決定】** 是 Alan 明確說過的；**【Claude 的判斷】** 是代為決定、Alan 可推翻的。

## 1. 要做的事

1. **後台可以自己新增互動樂譜，右手旋律兩種放法都要**【Alan 決定，10/30】
   - 上傳只有右手一行的 MusicXML（含和弦記號）——第一批會擋下單行譜，這次改成接受。
   - 在後台直接打簡譜：右手旋律＋每小節和弦（語法沿用原型「後台改譜」：`1`–`7` 音、`0` 休止、`-` 延長一拍、`'` 高八度、`,` 低八度、`_` 八分、`.` 附點、`#`／`b` 升降、`|` 小節線；和弦用 `|` 分小節、每小節 1／2／4 個，`C Am G7 Cmaj7 Dm7 Bdim Csus4 C/E`）。另有曲名、調號（1=C、1=G…）、拍號、速度欄位。【Claude 的判斷】存檔時轉成單行 MusicXML 存進 `scores.musicxml`，之後五線譜、簡譜、播放全部沿用同一條路，不另開資料格式。
2. **左手伴奏由系統依和弦產生，學員端有下拉選單切換**【Alan 決定，10/30：控制列加下拉選單「左手伴奏」，點哪一個左手就變成那種伴奏；型態一開始說參考 Ch8，後來定為照原型檔】
   - **型態照原型檔**【Alan 決定，10/30：「左手伴奏參考原檔案」】（`docs/superpowers/specs/assets/2026-10-29-score-prototype.html` 的 `PATTERNS`，L＝這個和弦佔的拍數）：
     - **柱式**：整段一個柱式和弦（slash 和弦把低音放最下）。
     - **根音＋和弦**：每拍一下，偶數拍彈低音（根音，若在 C3 以上降一個八度；第 3 拍改彈五度，slash 和弦除外）、奇數拍彈和弦三音；不到 2 拍就低音＋和弦一起按。
     - **分解**：四分音符「低音－五度－三度－五度」（比低音低的音升八度），依拍數截斷。
     - **琶音**：八分音符「根音（低八度）－五度－八度－十度－十二度－十度－八度－五度」，依拍數截斷。
     - 組成音與低音位置沿用原型 `makeChord`／`lhRoot`（根音落在 F2–E3 一帶）。
   - 原譜有左手（staff 2）時，選單多一個「原譜左手」並當預設【Alan 決定，10/30：有左手就照用老師編的】；只有右手時，預設「柱式」（原型預設 `pattern:'block'`）。
   - 沒有和弦名的單行譜：不產生左手，選單隱藏，只顯示右手。
   - 產生的左手在五線譜、簡譜、播放、高亮、鍵盤全部生效（同一份模型、同一組音符 id），A-B 循環、單手開關照常。
   - 後台可以設定該曲預設的伴奏型態（存在 `scores.meta.defaultAccompaniment`，不需改資料表）。
3. **預設顯示 Lead Sheet（只有右手），按「顯示左手」才出現左手**【Alan 決定，10/30，附原型截圖】
   - 控制列照原型加回「Lead Sheet」組，裡面是「顯示左手」開關，**預設關**；取代第一批的「只看右手」（第一批預設雙手、按鈕是隱藏左手，方向相反）。
   - 關著時：五線譜只畫右手一行（含和弦名）、簡譜只有右手行；播放【Claude 的判斷】照樣可以開左手聲音（右手／左手播放開關不受影響），學員先看旋律、聽完整伴奏。
   - 打開時：五線譜變大譜表、簡譜多左手行，左手內容依「左手伴奏」下拉選單。
   - 「節奏斜線」：【Claude 的判斷，照原型】加回 Lead Sheet 組，預設開（原型 `slash:true`），在右手下方標拍點；Alan 截圖上也是開著。
   - 下拉選單就是原型的四種（柱式、根音＋和弦、分解、琶音），名稱照原型。
4. **刪除放寬**【Alan 決定，10/30】：已發布的曲目也能直接刪（跳確認框，不必先下架）；舊版 ABC 小蜜蜂也能刪。刪除寫操作紀錄。

## 2. 技術做法（給實作者）

- `lib/score/musicxml.js`：單行譜（`<staves>` 不存在或為 1）改為接受，模型帶 `hasLeftHand:false`；兩行以上仍照第一批。`not_grand_staff` 只留給「三行以上／多樂器總譜」。匯入警告改說明「只有右手，左手會依和弦自動產生」。
- 新純函式 `lib/score/accompaniment.js`：`addAccompaniment(model, style) → model`（在 staff 2 產生音符、id 接在原有後面、依和弦起訖與小節長度切；弱起小節與沒有和弦的小節不產生），以及 `accompanimentXml(xmlText, model, style)` 產生給 OSMD 的兩行 XML（新增 staff 2、低音譜號、`<backup>`、音符，連桿交給 `prepareStaffXml`）。原型的 `lhRoot`／型態邏輯可移植（docs/superpowers/specs/assets/2026-10-29-score-prototype.html 的 `makeChord`、伴奏型態段）。全部 Vitest，至少測：四種型態在 4/4、3/4、6/8 的節奏與音高、slash 和弦低音、N.C. 小節留空、弱起、和弦在小節中間換、id 唯一。
- 新純函式 `lib/score/jianpu-input.js`：後台簡譜文字 → 單行 MusicXML（含 `<harmony>`）。錯誤要指出第幾小節、白話（沿用原型 `parseMelody`／`parseChords` 的檢查：每小節拍數要剛好、和弦數 1／2／4）。
- 學員端 `InteractiveScore`：「只看右手」改為「Lead Sheet → 顯示左手」（預設關＝只顯示右手；沿用 `rightHandOnly` 的繪製路徑，只是預設值與按鈕語意反過來，localStorage 記住學員的選擇）；控制列加「左手伴奏」下拉選單；切換時停止播放、重算模型與 XML（`useMemo`），StaffView 重畫並重建對照表。
- 後台 `ScoresManagePage`：新增表單加「上傳檔案／直接打簡譜」兩個頁籤；預覽、警告照舊；加「預設伴奏」下拉。刪除按鈕對所有列開放（確認框寫明「已發布的學員會立刻看不到」）；API `DELETE` 拿掉「已發布 409」與「ABC 409」限制。
- `docs/樂譜匯出說明-給Rick.md` 補一段：只打右手＋和弦記號也可以，左手系統會配；要老師自己的左手就打雙手。

## 3. 不做／維持

- 第一批其餘行為不變；正式站仍靠 `INTERACTIVE_SCORES` 開關，只在 preview。
- 伴奏不支援踏板、力度變化；不做「隨機變化」。
- MIDI、等待模式仍是第二批。

## 4. 驗收

1. `npm test`、`npm run build` 通過。
2. 後台：上傳單行 MusicXML、直接打簡譜各建一首，預覽時切換四種伴奏都對；可刪除已發布曲目與舊 ABC。
3. preview 學員端：進樂譜分頁預設只看到右手（Lead Sheet）；按「顯示左手」出現左手；1-2 單元下拉切換伴奏，五線譜、簡譜、播放、高亮、鍵盤同步改變；有原譜左手的曲子預設「原譜左手」。
4. 正式站行為不變。
